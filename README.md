AI Identity Security Capstone Project

Organization: SecureNova Inc.

Project Overview

This project focuses on securing an AI-powered customer support agent through identity and access management, threat modeling, red-team testing, blue-team defense, and security governance.

Repository Structure

1. 01-threat-model: AI system architecture, data flows, threat trees, and risk assessment.
2. 02-iam-design: Auth0 authentication, OAuth 2.0, token management, and access controls.
3. 03-red-team: Project 3 adversarial testing and attack evidence.
4. 04-blue-team: Project 4 security controls, mitigation scripts, and test evidence.
5. 05-policy: AI Identity Security Policy, credential governance, and incident response procedures.

Compliance Frameworks

- NIST AI Risk Management Framework (AI RMF)
- OWASP Top 10 for Large Language Model Applications

Objective

To identify AI identity security risks, implement appropriate security controls, and document the results through a structured security portfolio.
